# Coffee Shop Website ☕

## Overview
- Responsive Coffee Shop Website built using **HTML5** and **CSS3**
- Designed with a **min-width layout approach**
- Focused on clean UI and responsive structure

---

# Features

## Navigation Bar
- Logo and menu links
- Simple and clean navigation design
- Responsive alignment using Flexbox

## Hero Section
- Attractive coffee banner
- Promotional text with CTA button
- Background image implementation

## Top Categories
- Coffee category cards
- Image, title, and button included
- Card-based layout design

## Milkshake Products
- Product cards with:
  - Product image
  - Likes counter
  - Price
  - Buy button
- Reusable card structure

## Latest Blogs
- Blog cards with image and description
- “Read More” button
- Structured content layout

## Footer
- Company links
- Product categories
- Social media icons
- Multi-column footer layout

# Min-Width Usage
- Used `min-width` to maintain layout structure
- Prevents elements from shrinking too much
- Improves readability on smaller screens

### Example
```css
.container{
    min-width: 320px;
}
```
